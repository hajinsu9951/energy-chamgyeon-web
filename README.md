# 에너지참견시점 수업실

2026 에너지소양교육 교사연구회 「에너지참견시점」의 그린 벤처 프로젝트 다섯 프로그램을 수업 시간에 바로 운영하는 교육용 웹페이지입니다. 한국에너지정보문화재단의 지원을 받았습니다.

## 구조
```
index.html            허브 (도입 영상, 다섯 프로그램, 4대 주제 표, 적용 결과, 자료실, 사용법)
p1-korean/            프로그램 1 국어 및 가치 발견 (4차시) · 미림마이스터고 이대형
p2-math/              프로그램 2 데이터로 그리는 미래 에너지 (2차시) · 대전대신고 하진수
p2-math/lab/          행렬 × 탄소 실험실 (기존 웹 실험실)
p3-global/            프로그램 3 4색 글로벌 그린 창업기 (6차시) · 영훈고 임은희
p4-science/           프로그램 4 과학 및 지능형 최적화 (2차시) · 서울미술고 황호연
p5-tech/              프로그램 5 적정기술 프로토타이핑 (5차시) · 사당중 김이현
assets/               공통 스타일(site.css)·동작(site.js)·AI 생성 도입 영상(video/)
slides/p1~p5/         수업 PPT 슬라이드 이미지 (웹 뷰어용, 1600×900)
materials/            블랙골드 통일 PPTX·PDF 5종, 탄소배출권 시뮬레이터 xlsx
.nojekyll
```

## 쓰는 법
- 교실 화면: 오른쪽 위 '교사 모드'(발문·예상 답·유의점, 기기에 저장되지 않음), '크게 보기', '전체 화면'.
- 수업 진행 상자: ← → 또는 발표 리모컨 PageUp/PageDown으로 단계 이동, 단계마다 타이머.
- 학생 입력칸은 그 기기의 브라우저에만 저장됩니다. 바닥글 위 '내 기록 모두 복사 / 이 기기의 수업 기록 지우기'.
- 움직임 줄이기 설정을 켠 기기에서는 도입 영상이 자동으로 넘어가지 않습니다.

## 게시
- GitHub Pages: 이 폴더를 저장소 루트로 올리고 Pages를 켭니다(빌드 없음, `.nojekyll`).
- 원본 사진(얼굴 흐림 전, 제3자 사진)은 사이트 밖 `../웹_원본사진_비공개/`에 있으며 게시하지 않습니다.

## 표기
- 도입 영상(assets/video)은 생성형 AI로 만든 장면입니다.
- 학생 얼굴과 학번·이름은 흐리게 처리하거나 가렸습니다.
- 수치 출처는 각 프로그램 화면 바닥글과 교사 메모에 있습니다.
